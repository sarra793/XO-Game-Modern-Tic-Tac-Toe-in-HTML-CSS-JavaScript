# ❌⭕ XO Game — Modern Tic-Tac-Toe in HTML, CSS & JavaScript

## 📖 Overview

**XO Game** is a modern implementation of the classic **Tic-Tac-Toe** game built with **HTML**, **CSS**, and **Vanilla JavaScript**.

The project demonstrates fundamental web development concepts, including DOM manipulation, event handling, game logic, and responsive interface design.

---

## ✨ Features

- ❌ Two-player gameplay (X vs O)
- 🎯 Automatic win detection
- 🤝 Draw detection
- 🔄 Restart button
- 📱 Responsive design
- ⚡ Fast and lightweight
- 🎨 Modern and clean user interface
- 🚫 Prevents invalid moves

---

## 🛠️ Technologies Used

- 🌐 HTML5

## 🎮 How to Play

- Player **X** starts the game.
- Players take turns placing their symbol on the board.
- The first player to align **three symbols** horizontally, vertically, or diagonally wins.
- If all cells are filled without a winner, the game ends in a draw.
- Click **Restart** to start a new game.
